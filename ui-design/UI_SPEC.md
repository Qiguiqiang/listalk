# 声桥 AirBridge — UI 规格 v1

> 交付对象：Android 端（纯框架 View + Drawable，无 AndroidX / Material）与 PC 端（Python tkinter 状态窗）。
> 本规格所有数值可直接照抄实现；颜色、字号、圆角、间距均为最终值，不要再用系统默认灰。

---

## 1. 产品名与定位

| 项 | 值 |
|---|---|
| 中文名 | **声桥** |
| 英文名 | **AirBridge** |
| 全称写法 | 声桥 AirBridge（App 标题栏、启动页、PC 窗口标题统一） |
| 一句话定位 | 把手机变成电脑的麦克风和扬声器。 |
| 英文副标 | Your phone is now your PC's mic & speaker. |
| 气质 | 专业音频工具：深色、克制、状态一眼可读；不做社交 App 式花哨渐变堆叠，只用一处品牌渐变（图标与主按钮） |

包名不变：`com.qi.phoneaudiobridge`。显示名（`android:label` / PC 标题）改为「声桥 AirBridge」。

## 2. 设计 Token

### 2.1 颜色（深色优先，只做深色一套，v1 不做浅色）

| Token | Hex | 用途 |
|---|---|---|
| `bg` | `#0B0E13` | 页面背景（纯色即可；预览稿的微光晕不进 App） |
| `bgTop` | `#0E131A` | 顶部栏 / Hero 顶部渐变起色（可选，纯色 `bg` 亦可） |
| `surface` | `#151B24` | 普通卡片 |
| `surfaceHi` | `#1C2531` | Hero 卡、被选中的设备行、开关开启的通道卡 |
| `surfaceIn` | `#0F141C` | 内嵌区：电平表底槽、输入框、统计条 |
| `stroke` | `#26303F` | 卡片描边 1dp |
| `strokeHi` | `#334155` | 高亮描边（已连接设备行） |
| `accent` | `#2CE8A5` | 主色：已连接 / 推流中 / 麦克风通道 / 主按钮渐变起色 |
| `accentEnd` | `#17B978` | 主按钮渐变止色 |
| `accentDim` | `#12362A` | 主色弱底：已连接徽章、开启态开关轨道底 |
| `sky` | `#45C7F2` | 扬声器通道（电脑 → 手机）专属色，与麦克风的薄荷绿分工 |
| `skyDim` | `#12303F` | 扬声器色弱底 |
| `warn` | `#FFB224` | 延迟偏高、重连中、采样率已自动下调 |
| `error` | `#FF5C5C` | 断开 / 失败 / 延迟过高 |
| `errorDim` | `#3A1D22` | 错误弱底（错误条背景） |
| `text1` | `#F2F5F9` | 主文字 |
| `text2` | `#9AA7B8` | 次文字、说明 |
| `text3` | `#5F6D80` | 弱文字、占位、单位 |
| `onAccent` | `#052417` | 主色按钮上的文字（深色字，不要用白字） |

延迟徽章配色（硬规则，全端一致）：

| 延迟 | 颜色 | 文案档位 |
|---|---|---|
| < 30 ms | `accent #2CE8A5` | 流畅 |
| 30–80 ms | `warn #FFB224` | 一般 |
| > 80 ms | `error #FF5C5C` | 偏高 |

### 2.2 字体

- 字体族：系统默认 sans（Android：Roboto / Noto Sans SC；PC tkinter：Windows 用 `Microsoft YaHei UI`，Linux 用 `Noto Sans CJK SC`，回退默认）。
- 数字（延迟、采样率、统计）一律等宽：Android `monospace`，预览/PC 同理——数字跳动时界面不抖。

| 样式 | 大小 | 字重 | 用途 |
|---|---|---|---|
| `display` | 28sp | bold | Hero 延迟大数字 |
| `h1` | 20sp | bold | App 名、页面大标题 |
| `h2` | 16sp | bold | 卡片标题、电脑名 |
| `body` | 14sp | regular | 正文、列表主行 |
| `bodyS` | 13sp | regular | 说明、列表副行 |
| `caption` | 12sp | regular | 芯片、单位、脚注 |
| `micro` | 11sp | bold, 全大写英文 | 英文眉题（如 LIVE / MIC LEVEL） |

### 2.3 圆角与间距

- 圆角：Hero 卡 `24dp`，普通卡 `20dp`，通道卡 `18dp`，输入框/次按钮 `14dp`，主按钮 `18dp`，芯片/徽章 `999dp`（全圆）。
- 间距基数 4：`4 / 8 / 12 / 16 / 20 / 24 / 32`。屏幕左右边距 `20dp`，卡间距 `12dp`，卡内边距 `16dp`（Hero `20dp`）。
- 触控目标最小 `48dp`；主按钮高 `56dp`；开关行高 ≥ `64dp`。
- 描边统一 `1dp solid stroke`；卡片不用阴影（深色下阴影不可见），靠描边 + 色阶分层。

### 2.4 Android 实现映射（框架原生，零第三方库）

| 视觉件 | 实现 |
|---|---|
| 卡片 | `GradientDrawable`：`res/drawable/bg_card.xml`（`surface` + 圆角 20 + stroke），Hero 用 `bg_hero.xml`（`surfaceHi` + 圆角 24 + `strokeHi`） |
| 主按钮 | `bg_btn_primary.xml`：线性渐变 `accent → accentEnd`、圆角 18；文字 `onAccent`、16sp bold。停止态换 `bg_btn_stop.xml`（`errorDim` 底 + `error` 字 + 1dp `error` 描边） |
| 芯片 | `bg_chip.xml`（`surfaceIn` + 全圆 + stroke），图标点用 6dp 圆形 `View` 背景 `bg_dot_accent.xml` 等 |
| 电平表 | 一排 24 个 `View`（宽 4dp、高 22dp、间距 3dp，`bg_meter_seg.xml` 圆角 2dp），按电平点亮个数着色：前 70% `accent`/`sky`，70–90% `warn`，>90% `error`。Activity 现有 500ms 轮询改为 100ms 刷新电平即可（仅重绘小 View，开销可忽略） |
| 开关 | 用 `Switch` 系统控件 + `thumb/ track` 着色到 `accent/accentDim`（麦克风）与 `sky/skyDim`（扬声器）；或保留现有 `CheckBox` id，外观换自定义 drawable。**id 不变原则见 §3.4** |
| 雷达动画（搜索态） | 一个 `View` 自绘或三层同心圆 drawable + `ObjectAnimator` 缩放/透明度循环；低端实现：静态同心圆 + 「正在搜索…」呼吸点即可，不阻塞功能 |
| 图标/Logo | 见 §6，SVG 源文件 `icon.svg` 同目录 |

PC（tkinter）映射：`bg` 作窗口底，卡片用 `Frame(highlightbackground=stroke, highlightthickness=1, bg=surface)`，字体按上表减 2 号（桌面密度），主色/延迟色同值。禁止用 tkinter 默认灰底白按钮交付。

## 3. Android 界面

单 Activity、单页纵向滚动（`ScrollView` 包根 `LinearLayout`），三态共用同一骨架，靠显隐区块切换——不要做多页面跳转。

### 3.1 骨架（三态共有）

```
ScrollView (bg)
└─ LinearLayout vertical, padding 20dp
   ├─ Header: [Logo 36dp] 声桥 AirBridge (h1)        [状态点+状态字]
   │          把手机变成电脑的麦克风和扬声器 (bodyS, text2)
   ├─ Hero 卡 (bg_hero)            ← 三态内容不同，见 3.2
   ├─ 通道卡 ×2 (麦克风→电脑 / 电脑→扬声器)  ← 仅已连接后出现
   ├─ 设备区 (发现列表 / 手动 IP)            ← 仅未连接时出现
   ├─ 主按钮 (56dp, 整宽)
   └─ 脚注 (caption, text3, 居中)
```

### 3.2 三态

#### (a) 未连接 / 搜索中

```

│ 把手机变成电脑的麦克风和扬声器   │
├──────────────────────────────────┤
│ Hero:                            │
│        ( ◯ )  同心圆雷达          │
│   正在寻找你的电脑…              │   h2
│   确保电脑端已打开，且与手机      │   bodyS text2
│   连着同一个 WiFi                │
│   ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─          │
│   附近的电脑              刷新⟳  │
│  ┌────────────────────────────┐  │
│  │ 🖥 QI-PC          192.168.1.20│ │  设备行 64dp：名称 body 粗 +
│  │    Windows · 已就绪    [连接] │ │  副行 caption text2 + 右侧文字按钮
│  └────────────────────────────┘  │
```

- 空结果（搜 5 秒无设备）：列表区换空态文案「还没找到电脑」+ 副文案（见 §5），雷达继续转。
- 点设备行或「连接」→ 进入连接中：该行变 `surfaceHi` + 右侧转「连接中…」，主按钮禁用。

```

│                                      │
│  [48 kHz] [WiFi] [UDP · 10ms]        │  芯片行

```

- 任一通道关：对应电平条变灰（`text3`）、副行变「已暂停」，Hero 不变。
- 采样率被自适应下调：`48 kHz` 芯片变 `warn` 色并改文案「24 kHz · 已自动优化」，恢复后变回。
- 延迟变色：徽章按 §2.1 表实时换色，数字始终等宽。

### 3.3 断线 / 重连中（覆盖态，不跳页）

Hero 顶部插入一条 `warn`/`errorDim` 横条：「连接中断，正在重连…（第 2 次）」，电平冻结归零，主按钮变「立即重连」+「停止」。重连成功横条消失并闪一次「已重新连接」。超过 30 秒未恢复 → 横条变 `error` 版文案（见 §5）。

### 3.4 与现有代码的衔接（给构建 Agent）

- 保留现有 id：`btnStart`（主按钮，文案随态变：开始搜索/开始推流/停止推流，一颗按钮三态，`btnStop` 仅作停止态复用或隐藏）、`tvStatus`（映射 Header 状态字）、`listPc`（设备行套自定义行布局，名称+副行+连接钮）、`etManualIp`、`btnConnectManual`、`cbMic`/`cbSpeaker`（换 Switch 外观，监听不变）、`tvStats`（拆进 Hero 统计行，文案格式不变）。
- 新增 View id 建议：`heroCard`、`tvLatencyBadge`、`meterMic`、`meterSpk`、`chipRate`、`chipTransport`、`tvElapsed`、`seekVolume`、`bannerReconnect`。
- 所有新 drawable 放 `res/drawable/`，命名按 §2.4。

## 4. PC 端界面（tkinter 状态窗）

窗口 `520 × 680`，不可缩放，标题「声桥 AirBridge」，与手机端同一套 token。

```
┌─ 声桥 AirBridge ──────────────────────┐
│ ● 等待手机连接            [端口 47731] │  Header：状态点+字 / 右侧端口芯片
│ 把电脑变成手机的外接声卡               │  bodyS text2
├────────────────────────────────────────┤
│ Hero 卡                                │
│  已连接手机                            │  眉题 CONNECTED（未连接时整卡换空态）
│  Xiaomi 13 · 192.168.1.42              │  h2 + bodyS
│  [ 18 ms · 流畅 ]                      │  延迟徽章，同色规则
│  延迟曲线 ▁▂▃▂▅▃▂▁▂▃ (近 60 秒)       │  Canvas 60×520 折线，accent 描线，
│                                        │  下半透明填充；丢包以 warn 点标记
│  丢包 0.3% · 抖动 2ms · 缓冲 20ms      │  统计行，等宽
├────────────────────────────────────────┤
│ 音频设备                               │
│  手机麦克风输出 → [VB-CABLE Input  ▾]  │  下拉 + 右侧徽章
│                    ✓ 已自动识别虚拟声卡 │  accentDim 底徽章（识别到时）

│                    ✓ 已自动识别虚拟声卡 │
│  未装虚拟声卡时：提示条 + 「安装指南」 │  warn 条，按钮打开 README 章节
├────────────────────────────────────────┤
│ 通道： [✓] 麦克风 → 电脑  [✓] 电脑 → 手机│  两个 Checkbutton，与手机端呼应

└────────────────────────────────────────┘
```

- 延迟/丢包图：`Canvas` 每秒推一个点，保留 60 点；实现成本低，必须做——这是 PC 端唯一的"产品感"动态元素。

## 6. 图标 / Logo

- 源文件：同目录 `icon.svg`（本规格随附，可直接转 Android VectorDrawable / PNG 各密度）。
- 构成：圆角方形深底（`#0B0E13`→`#151B24` 微渐变）上，5 根竖直声波柱居中，中间最高一根与两侧以一条弧线相连——弧线既是"桥"，也是链环的一半；声波柱用主渐变 `accent → sky`（左绿右蓝，正好对应麦克风/扬声器两条通道）。
- 规则：柱宽与间距 1:1，最矮柱不低于最高柱 35%；任何尺寸下不加文字；安全边距 18%。
- 内页小 Logo 直接复用图标去掉底板、单色 `text1` 版式即可，不另画。

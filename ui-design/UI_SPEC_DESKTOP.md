# 声桥 AirBridge — 桌面端（Windows）UI 规格 v1

> 配套原型：`preview_desktop.html`（同目录，浏览器打开，顶部有状态切换条）。实现时以原型逐项对版：颜色零误差、间距允许 ±2px。
> 设计基线：沿用手机端 `UI_SPEC.md` 的全部 token 与文案口径，只改**布局与密度**——桌面是横向工作台，不是放大的手机页。对标体感：UU 远程 / TeamSpeak / Discord 的侧边栏应用结构。
> 实现端：Avalonia 11（.NET 8），下方每个组件都给了 Avalonia 落点，照抄即可。

---

## 1. 窗口骨架

| 项 | 值 |
|---|---|
| 默认尺寸 | **1160 × 680**，最小 **940 × 580**，可缩放、可最大化 |
| 结构 | 自绘标题栏（40px）＋ 左侧边栏（232px 固定）＋ 右主区（自适应） |
| 标题栏 | 左：小 Logo + 「声桥 AirBridge · {本机名}」；右：最小化 / 最大化 / 关闭三键（46×40），关闭键 hover 红底 `#E81123`。关闭 = 最小化到托盘（设置可改），不是退出 |
| 主区通用 | 顶部状态条 46px（当前状态 + 关键指标 + 右侧芯片）＋ 下方滚动内容区，内容左右边距 22px、上 20px |
| 分层 | 背景 `bg` → 卡片 `surface` + 1px `stroke` → 内嵌区 `surfaceIn`。深色下不用阴影分层，靠色阶 + 描边；仅弹窗/下拉/托盘菜单用阴影 |

**Avalonia 实现要点**
- `Window` 设 `ExtendClientAreaToDecorationsHint=True`、`ExtendClientAreaTitleBarHeightHint=40`，标题栏用 `Grid` 自绘，三键为原生 `Button` 样式覆盖；拖动用 `BeginMoveDrag`。
- 根布局 `Grid ColumnDefinitions="232,*"`；侧边栏 `Border`（背景 `#0D1118`、右边框 1px `stroke`）；主区每页一个 `UserControl`，用 `ContentControl` + DataTemplate 或直接显隐切换。
- 滚动区用 `ScrollViewer`，滚动条样式细化（宽 9px、thumb `#232E3F`）。

## 2. 桌面密度调整（与手机规格的差异，仅此几处）

手机 token 原值不变，只调字号与圆角密度：

| 样式 | 手机 | 桌面 | 用途 |
|---|---|---|---|
| 页面大标题（设备名） | 20sp | **19px / 700** | Hero 设备名 |
| 卡片标题 | 16sp | **14px / 700** | 通道卡、分组标题 |
| 正文 | 14sp | **13.5px** | 设置行标题、设备行名 |
| 说明 | 13sp | **11.5–12.5px** | 副行、说明文字（`text2`） |
| 眉题 micro | 11sp | **10.5px / 700 / 字距 .16em / 全大写英文** | LIVE、MIC LEVEL 等 |
| 数字 | 等宽 | **Consolas / JetBrains Mono** | 延迟、IP、码率、统计一律等宽，跳动不抖 |
| 圆角 | 卡 20dp | **卡 14px、Hero 16px、内嵌 9–12px、徽章 999px** | 桌面密度更紧 |
| 卡内边距 | 16dp | **16–18px**，Hero 20–22px | — |

颜色全部沿用 `UI_SPEC.md` §2.1（含延迟徽章硬规则：<30ms `accent`「流畅」/ 30–80 `warn`「一般」/ >80 `error`「偏高」）。

**Avalonia 实现要点**：token 落成 `ResourceDictionary`（`Colors.axaml` + `Styles.axaml`），命名与 token 同名（`BgBrush`、`SurfaceBrush`、`AccentBrush`…），任何控件禁止写死颜色值。

## 3. 组件清单

### 3.1 侧边栏 Sidebar
- 品牌区：Logo（icon.svg 去底板、声波柱渐变版，38px 圆角方）＋「声桥」16.5px/700 ＋眉题 `AIRBRIDGE` 10.5px `text3`；底部 1px 分隔线。
- 导航项：高 38px、圆角 9px、图标 17px（线性 SVG 风格，描边 1.8）＋文字 13.5px。态：默认 `text2` → hover `surface` 底 → 选中 `surfaceHi` 底 + `stroke` 描边 + 左侧 3px `accent` 竖条 + 文字 600。
- 「更新」项右侧红色圆点（有新版本时）；「关于」项右侧显示当前版本号（等宽 `text3`）。
- 连接状态卡（底部上方）：`surface` 卡，呼吸绿点 + 「推流中 · {手机名}」13px/600 + 等宽副行「WiFi · 18 ms · 48 kHz」11.5px。未连接时换灰点 + 「未连接」+「等待手机连接」。
- 底栏：左侧版本号 `v2.1.0`（等宽 `text3`）；右侧「有新版本 2.2.0」`warn` 底胶囊按钮，点击打开更新弹窗。无更新时不显示。

**Avalonia**：导航用 `ListBox` 自定义模板或一排 `RadioButton` 改样式；状态卡绑定 `ConnectionState`；呼吸点用 `Ellipse` + Opacity/Scale 动画（`Animation` 或代码定时器）。

### 3.2 状态条 StatusBar（主区顶部）
高 46px，半透明 `surface` 底 + 底部描边。左：状态点 + 状态词 13px/600（推流中/已连接/未连接/重连中，词表见手机规格 §5）；中：分隔线 + 等宽指标（已推流时长、安心文案）；右：信息芯片（`UDP · 10 ms 帧`、`端口 47731`）。重连中时整条换 `warn` 语义文案（「连接中断，正在重连…（第 n 次）」），与手机端横条同文案。

**Avalonia**：`Border` + `StackPanel` 横排；状态词与颜色绑 ViewModel 属性，颜色走资源键切换。

### 3.3 设备 Hero 卡
`surfaceHi→surface` 微渐变 + `strokeHi` 描边、圆角 16、内边距 20×22。内容：手机图标块 52px（`surfaceIn` 底）→ 眉题「● LIVE · 已连接手机」（`accent`）→ 设备名 19px/700 + 延迟徽章（`accentDim` 底胶囊，大数字等宽 16px/700 +「ms · 流畅」）→ 等宽副行「{IP} · Android {版本} · 声桥 App v{x}」→ 芯片行（连接方式 / 采样率 / 回声消除 / 手机电量）。右上角「断开连接」按钮（`errorDim` 底、`error` 字、hover 加深）。

**Avalonia**：`Border` + `Grid`；延迟徽章三色按 §2 表切资源；电量来自手机端心跳字段，无数据时整芯片隐藏，不显示假值。

### 3.4 统计条 StatsStrip
5 格等宽横排（丢包率 / 抖动 / 抖动缓冲 / 上行码率 / 下行码率），格间 1px `stroke` 分隔；标签 11px `text3`，值 14.5px/600 等宽 + 单位小字 `text2`。

### 3.5 延迟曲线 Sparkline
卡片内 44px 高曲线：近 60 秒、每秒 1 点，`accent` 描线 1.6px + 下方 9% 透明填充；左上标签「延迟 · 近 60 秒」、右上「当前 {n} ms」等宽。丢包尖峰点用 `warn` 小点标出（原型从简，产品版补）。

**Avalonia**：`Canvas` 自绘 `Polyline` + `Polygon` 填充，环形缓冲 60 点，1s 定时刷新——与手机规格 §4 对 PC 端的要求一致，这是桌面端唯一的常驻动态图，必须做。

### 3.6 通道卡 ChannelCard ×2
并排两列（`Grid` 1fr/1fr，间距 14），窄窗口（<940）时改单列。结构：
- 头：通道图标块 34px（麦克风 `accentDim` 底绿图标 / 扬声器 `skyDim` 底蓝图标）+ 标题 14px/700 + 副行说明 11.5px；右侧通道开关。
- 电平表：眉题行（`MIC LEVEL` / `SPEAKER LEVEL` + 右侧等宽 dB 值）+ **28 段**分段条（每段高 16px、圆角 2.5、间距 2.5），点亮规则同手机规格：前 72% 通道色、72–90% `warn`、>90% `error`；刷新 100ms。通道关时整卡降透明度到 .62、电平归零、dB 显示「— dB」。
- 设备选择器（见 3.7）：麦克风卡 = 「输出到电脑的设备」，扬声器卡 = 「采集电脑上的哪个声音」。
- 仅扬声器卡有音量滑杆（手机播放音量，`sky` 着色，右侧等宽百分比）。

**Avalonia**：电平表用 `ItemsControl` + 28 个 `Border` 或单个自绘 `Control`（推荐自绘，100ms 重绘开销最低）；开关用 `ToggleSwitch` 改模板到本规格尺寸（42×24、圆钮 18）；滑杆 `Slider` 改轨道/圆钮着色。

### 3.7 设备选择器 DevicePicker
按钮式下拉：`surfaceIn` 底、圆角 9、高约 34，显示当前设备名 + 右侧标签胶囊（`声桥设备` 绿/蓝 或 `备用`）+ chevron。展开菜单：浮层 `#1A2230` + `strokeHi` 描边 + 阴影，项高约 32，hover `surfaceHi`，选中项 600 字重 + 右侧标签（推荐/备用）。
选项口径（与路由规则一致，防环路）：
- 麦克风输出：麦克风（声桥 AirBridge 虚拟音频设备）→ CABLE Output → 本机硬件麦克风。
- 扬声器采集：扬声器（声桥 AirBridge 虚拟音频设备）→ CABLE Input → 本机硬件扬声器 → 系统默认输出。
- **冲突项必须置灰并标注「会与麦克风通道形成回路」**（v2.1 路由冲突规则的 UI 呈现），不允许用户选出环路组合。

**Avalonia**：`ComboBox` 深度改模板，或 `Button` + `Popup`（原型即此形态，推荐后者，样式可控）。冲突置灰逻辑读 ViewModel 的 `RoutingConflict` 判定。

### 3.8 开关 Switch
42×24（设置页小号 38×22）：关 = 轨道 `#2A3648`、圆钮 `#8B98AB`；开 = 轨道通道弱底（`accentDim`/`skyDim`）、圆钮通道色。动效 150ms 滑动。设置页通用开关用 `accent` 系。

### 3.9 设备行 DeviceRow（发现页）
高约 66px：设备图标块 40px + 名 14px/600 + 等宽副行（IP · 连接方式 · 上次连接时间）+ 状态胶囊（推流中 `accentDim` 绿 / 离线 灰描边 / 未配对 `warn` 弱底）+ 右侧操作（已配对：自动连接开关；未配对：「配对」主按钮）。
已配对行用 `strokeHi` 描边 + 微渐变，与新设备行区分。扫描中顶部有虚线描边「扫描条」：旋转环 + 「正在扫描附近的手机…」+ 三路发现说明 + 右侧本机信息芯片。

### 3.10 设置行 SettingRow / 分段选择 SegmentedControl
设置页按分组卡（连接与重连 / 音频 / 更新 / 通知）：组标题 12px/700 `text3` 字距 .1em；行间 1px 半透明分隔。每行：左标题 13.5px/600 + 说明 11.5px `text2`（行高 1.5），右控件（开关 / 分段 / 输入框 / 按钮）。
分段选择：`surfaceIn` 底 + 3px 内边距，选中项 `surfaceHi` 底 + 600 + 微阴影。文本输入（如更新地址）：等宽 12px、宽 300、focus 时描边 `accent`。

**Avalonia**：设置行做成 `UserControl`（Title/Description/Content 三属性）；分段用 `ListBox` 横排改模板或 `RadioButton` 组。

### 3.11 更新弹窗 UpdateDialog
遮罩：全窗 `rgba(4,6,10,.66)` + 轻模糊；弹窗 440px、底 `#141A24`、`strokeHi` 描边、圆角 16、内边距 24×26。结构：图标块 + 「发现新版本」16.5px/700 + 版本行等宽（`v2.1.0 → v2.2.0`，新版本号 `warn` 色 + 大小 + 「已通过 SHA-256 校验」）→ 更新日志块（`surfaceIn` 底，条目式、关键词加粗）→ 下载进度（标签 + 等宽百分比 + 7px 进度条，品牌渐变填充）→ 按钮行（稍后提醒 = 幽灵按钮 / 下载并安装 = 主按钮渐变）→ 脚注（两端同版本提醒）。
校验失败态：进度条换 `error`、文案「校验不通过，已删除下载文件」，只留「关闭」按钮——不给重试安装入口。

**Avalonia**：`Window` 模态或主窗内 `Panel` 覆盖层（推荐覆盖层，与原型一致）；进度绑 `UpdateService` 的真实下载进度，不得做假动画。

### 3.12 托盘菜单 TrayMenu
原生托盘右键菜单的视觉稿（宽 238）：头部（状态点 + 名 + 状态行 `accent` 小字）→ 打开主窗口 / 暂停推流 → 分隔 → 两通道勾选项（✓ 通道色）→ 分隔 → 断开 {手机名} / 设置… → 分隔 → 退出声桥。

**Avalonia**：用 `TrayIcon` + `NativeMenu`（系统原生菜单，样式随系统，此稿为项序与文案标准，不强求像素一致）；左键单击托盘 = 打开/聚焦主窗口。

## 4. 页面与状态

| 页面 | 入口 | 关键状态 |
|---|---|---|
| 设备（推流中） | 侧边栏「设备」默认页 | Hero + 统计 + 曲线 + 双通道卡；通道独立开关；断开按钮 |
| 设备（未连接） | 同页换态 | Hero 换空态：「等待手机连接」+ 本机 IP 列表 + 「在手机上打开声桥即可自动找到这台电脑」；通道卡隐藏，改显发现入口卡 |
| 设备发现 / 配对 | 未连接空态入口 / 侧边栏（后续可加导航项） | 扫描条 + 已配对列表（自动连接开关）+ 附近新设备（配对按钮） |
| 设置 | 侧边栏「设置」 | 四组设置，改即生效；重连三模式、采样率策略为分段选择 |
| 更新弹窗 | 侧边栏更新项 / 底栏胶囊 / 设置页检查按钮 | 发现 → 下载中（进度）→ 校验通过待安装 / 校验失败（删除 + 报错） |
| 关于 | 侧边栏「关于」 | Logo + 版本 + 一句话定位 + 协议/组件说明（原型未单画，沿用设置页行样式即可） |

断线重连：不跳页，状态条变 `warn` 文案、电平冻结归零、Hero 延迟徽章换「重连中」，恢复后闪一次「已重新连接」。与手机端覆盖态同口径。

## 5. 文案

全部沿用手机规格 §5 的 PC 表，并补桌面新增项：

| 场景 | 文案 |
|---|---|
| 侧边栏状态卡 | 推流中 · {手机名} / 未连接 · 等待手机连接 |
| 底栏更新胶囊 | 有新版本 {x.y.z} |
| 发现页扫描条 | 正在扫描附近的手机… / 通过局域网广播、mDNS 与蓝牙近感三路并行查找 |
| 已配对副行 | {IP} · {WiFi/USB} · 上次连接 {时间} |
| 配对脚注 | 配对时手机上会弹出确认，核对两端显示的 6 位配对码一致即可 |
| 设置·重连 | 每次询问 / 总是自动连接 / 从不自动（短暂掉线始终自动续连，说明里写明） |
| 设置·虚拟设备行 | 已安装 · 扬声器 / 麦克风（声桥 AirBridge 虚拟音频设备）／未安装时换 warn 文案 + 「安装指南」按钮 |
| 更新弹窗 | 发现新版本 / 稍后提醒 / 下载并安装 / 校验失败：校验不通过，已删除下载文件 |
| 托盘 | 打开主窗口 / 暂停推流 / 断开 {手机名} / 设置… / 退出声桥 |
| 页脚 | 关闭窗口将最小化到系统托盘，推流不会中断 |

## 6. 验收（原型 → exe 对版清单）

1. 窗口默认 1160×680 打开截图与原型同视口截图逐区对照：侧边栏宽、状态条高、Hero 高度误差 ≤4px，颜色取色零误差。
2. 电平表 28 段、100ms 刷新无卡顿；关通道时整卡变灰且电平归零。
3. 延迟徽章三档颜色各截一图核对（可造假数据切档）。
4. 940×580 最小尺寸下无横向滚动条、无控件重叠（通道卡转单列）。
5. 更新弹窗四态各截一图：发现 / 下载中 / 待安装 / 校验失败。
6. 托盘菜单项序与文案与 §3.12 一致。
